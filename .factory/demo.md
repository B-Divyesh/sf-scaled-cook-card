# Demo sandbox

Open `/?demo=1` or `/demo` to start directly with the Weeknight tomato pasta sample. The demo loads the ready-to-cook card immediately, including five ingredients, four linked preparation steps, and the completion ledger.

Demo cook cards, serving changes, and corrections use browser-local keys beginning with `demo:scc:`. The normal product uses `scc:` keys, so demo activity never reads or writes a real cook card. **Reset demo** restores the shipped sample. **Start for real** discards demo data and returns to the blank landing page. The home wordmark also discards demo data before leaving.

The demo works after the initial online visit because the same app shell and sample recipe are available offline.
Cook mode also demonstrates arrow-key controls and the optional screen-wake request without changing real cook-card data.
