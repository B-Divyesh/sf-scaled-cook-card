# Demo sandbox

Open `/demo` to start directly with the Weeknight tomato pasta sample. The demo loads the ready-to-cook card immediately, including five ingredients, four bound preparation steps, and the completion ledger.

Demo cards, serving changes, and corrections use browser-local keys beginning with `demo:scc:`. The normal product uses `scc:` keys, so demo activity never reads or writes a real card. The persistent banner provides **Reset demo** to restore the shipped sample and **Start for real** to discard demo data and return to the blank landing page.

The demo works after the initial online visit because the same app shell and sample recipe are available offline.
